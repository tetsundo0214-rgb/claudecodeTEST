# Simple Alarm

シンプルな UI のブラウザ向けアラームアプリです。HTML / CSS / JavaScript のみで動作し、ビルドや依存ライブラリは不要です。

## 機能

- 現在時刻のリアルタイム表示
- アラームの追加 / 削除
- 有効・無効のトグル切り替え
- 設定したアラームを `localStorage` に保存
- アラーム時刻になるとビープ音で通知

## 使い方

`index.html` をブラウザで開くだけで利用できます。

```sh
# 例: ローカルで簡易サーバを立ち上げる
python3 -m http.server 8000
# その後 http://localhost:8000 を開く
```

ブラウザの自動再生ポリシーにより、最初に画面上で 1 度操作してからアラーム音が鳴ります。

## ファイル構成

- `index.html` — 画面のマークアップ
- `style.css` — スタイル
- `script.js` — アラームのロジック
